## 教訓（已下推）

- 文件剛更新 ≠ 服務已部署；lastModified 不是 runtime 證據。消費新 spec
  前先打一發驗 shape。
- 200 缺語意承重欄位 = protocol mismatch → 降級，絕不 default——default
  會憑空製造語意值（is_cancellable 缺 → false = 謊報不可取消）。已開
  factory lesson PR。
