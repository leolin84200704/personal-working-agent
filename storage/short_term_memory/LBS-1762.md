## Lessons Learned

### [2026-08-27]
- **診斷**：ehr_integrations 的 updated_at 是 app-managed（prisma @updatedAt）——raw SQL UPDATE 不會動它、也不留 note。「值變了但 updated_at/notes 無痕」= 有人直接下 SQL，可用來區分 manual IT fix vs API 路徑。
- **工具**：grpcurl client 被 kill 不會取消 server 端 NestJS gRPC handler——in-flight repush 會自己跑完；重跑前必查 rtr 最新 row，避免重複觸發。
- **工具**：GenerateResultHl7 是同步 RPC（~50-60s/call 含 SFTP upload）；批次 17 個 + 8s pacing 會超過 Bash 10-min timeout — 一開始就用 run_in_background。
- **驗證**：vendor SFTP listing 可用 emr-v2 node_modules 的 ssh2-sftp-client + ehr_vendors 表 creds 直接做，post-verify 不必止步於 rtr TRANSMITTED。
