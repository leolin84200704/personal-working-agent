## Answers to the ticket's three questions

1. Cerbo payload DOES include the patient address; emr-v2 parses it correctly.
   It is not "mapped into Vibrant" because (a) place-order carries no address by
   design and (b) the existing patient records' address rows are empty and inbound
   addresses are not persisted for existing patients.
2. Yes — Online Payment → patientPayLater → automatic payment-link email to the
   patient. Both were verifiably sent 2026-08-19 17:17Z.
3. Current behavior: the existing record's address IS what downstream uses; the
   file address is only used for order-level decisions. These records are empty →
   nothing to show. Whether inbound order address should backfill/update an
   existing patient record is a product decision (recommended: backfill when
   record has no usable shipping address).
