# PO-256 — Can not submit tube count

## Ticket Analysis
- Reporter Zihan Zhang (accessioning), 14:24 PT 2026-07-29; Xiaoye escalated 14:41 ("没法收货了"). Screenshot: Accession > Scan, "Update quantity for Tube Info" modal (BRANTLEY MCNICOL, accession 2607076858), Confirm → spinner forever.
- FE: LIS-frontend `UpdateTubeInfoDialog.vue` confirmTubeInfoUpdate → `shippingService.post('/orders/boxes/samples/tubes')` → LIS-Shipping (AKS lisportalprod, ns shipping) `OrdersTubesService.receiveTubes`, guarded by PermissionGuard → CheckPermission gRPC → coresamples-v2 (ns coresamplesv2, Go) → **RBAC Container App** (Azure Container Apps, 5s/call timeout).

## Findings (evidence, prod logs)
- Incident window **21:17–21:32Z (14:17–14:32 PT)**: RBAC Container App gRPC calls timed out (DeadlineExceeded); shipping returned **403 "Permission denied: CheckPermission RPC ... DeadlineExceeded"** after ~17s (≈3 retries x 5s + overhead).
- Impact in LIS-Shipping: 35 requests 403'd — 22 POST /orders/boxes/samples/tubes (tube receive), 12 PATCH /orders/samples/phlebotomists, 1 POST /orders/boxes/samples. Screenshot accession 2607076858 hit it at 21:27:44Z.
- Shipping pods healthy (3d14h, no restart, no deploy that day; origin/master last commit 7/15). coresamples-v2 pods healthy 25h, no error burst in window → stall was in the RBAC Container App itself (couldn't inspect: az MFA expired; platform-team scope).
- **Recovered**: last 403 at 21:32:19Z; 201s flowing from 21:33; 12-min recheck at ~21:50Z = 0 RBAC errors, all 200/201 fast.
- FE defect (why "rotate forever" instead of an error): axios 403 throws → confirmTubeQtyUpdate catches and returns undefined → caller does `res.data.code` → TypeError outside any try/catch → `changeLoadingState(false)` never runs → modal spins forever, no error shown, user cannot retry.

## Root cause
RBAC Container App outage/stall 14:17–14:32 PT made permission checks time out → tube-count submits 403'd; the LIS-frontend dialog's broken error path turned the 403 into an infinite spinner. Self-recovered after ~15 min; underlying Container App cause needs platform-team look (Azure metrics/logs).
