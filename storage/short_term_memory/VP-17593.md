# VP-17593 — booking verification email → Azure notification Event Hub

## Origin

(+ CDC topics 153_* from 60.2) TODAY. Full audit of emr-v2 + transformer found this as the one

(`KAFKA_BROKER_carlos*` 60.9/60.10:9095, topic `Notification-Email-Template`), throws on failure,

  dropped (no transitive DI consumer — verified public_booking + meeting-request).
- No config change needed: `Azure_kafka_notification_*` already in both ConfigMaps + injected.
- Tests: +4 unit (topic/schema/array recipients/failure/producer reuse) 4/4; tsc 37 pre-existing
  errors before AND after (none in touched files).
